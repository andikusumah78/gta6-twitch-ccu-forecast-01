Forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour: for each of hours 2–24 (UTC) it writes the 5%, 25%, 50%, 75% and 95% quantiles, fitted from past big launches' release-day curves. Practice pinball loss 0.250 on the log scale, against the house baseline's 0.387.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
